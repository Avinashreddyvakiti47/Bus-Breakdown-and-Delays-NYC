# 🚌 Bus Breakdown and Delays – NYC

## 📌 Project Overview

This project analyses bus breakdowns and delays in New York City using Microsoft Excel. The data was cleaned, transformed, and analysed to identify patterns in bus service disruptions and operational performance.

---

## 🎯 Objective

The goal of this project is to:

- Clean raw transportation data
- Analyse the main causes of bus breakdowns
- Identify delay patterns
- Create an interactive Excel dashboard for decision-making

---

## 🛠️ Tools Used

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

---

## 📊 Project Workflow

1. Imported the raw dataset
2. Cleaned missing and inconsistent data
3. Created Pivot Tables
4. Built interactive charts
5. Designed an Excel dashboard

---

## 📈 Key Insights

- Identified common reasons for bus breakdowns
- Analysed delay trends
- Compared operational performance
- Built an interactive dashboard for reporting
